PyApiSoccer365 — это асинхронный Telegram-бот, который помогает пользователям быть в курсе расписания матчей своих любимых футбольных команд. 
Бот автоматически собирает данные с популярного спортивного портала soccer365.ru, сохраняет их в базу данных и предоставляет удобный доступ к информации прямо в мессенджере.

Основные возможности:
- Выбор любимой команды: Пользователь может последовательно выбрать чемпионат (лигу) и свою любимую команду из предложенного списка.
- Просмотр ближайшего матча: После выбора команды бот мгновенно находит и отображает информацию о ближайшей предстоящей игре: дату, время, соперника и место проведения (дома или в гостях).
- Подписка на рассылку: Бот позволяет оформить подписку на ежедневные напоминания о матчах выбранной команды.
- Автоматическое обновление расписания: Встроенный планировщик задач (job_queue) ежедневно обновляет расписание матчей в базе данных, чтобы информация всегда была актуальной.
- Ежедневные напоминания: Каждое утро подписчики получают уведомления о предстоящих играх.
- Очистка базы данных: Бот автоматически удаляет устаревшие (прошедшие) матчи из базы, поддерживая её в чистоте.

Технологический стек
Язык: Python
Библиотеки:
- python-telegram-bot — для взаимодействия с Telegram API.
- SQLAlchemy — для работы с базой данных (ORM).
- BeautifulSoup4 — для парсинга HTML-страниц.
- fake_headers — для обхода базовой защиты при парсинге.
- pytz — для корректной работы с часовыми поясами.
База данных: SQLite (database.db).
